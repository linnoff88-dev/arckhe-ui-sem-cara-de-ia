In a few words

UI Without the AI Look is a free checker for websites and apps built with AI. It reads your project, points out what looks automatic or is hard to use, and prepares a fix request to paste into Claude Code or Codex. It is for people who build with these tools, even if they are not design experts. It does not change any files: your AI makes the fixes after you say yes.

How it works

Three questions, no jargon

It works like an inspector walking through a building with a clipboard. They write down what they see and do not break any walls.

🪪 Does it look like yours?

It looks for default colors, fonts, and corners. It is like opening a store with the supplier’s sign still on the door. This part only works for projects that store these choices in a theme, a single file with the system’s colors and sizes. Your AI checks whether yours has one.

🖐️ Does it work for everyone?

It looks for things that seem fine in a picture but fail when people use them: a makeshift notice, a drawer that will not slide, or a button the keyboard cannot reach.

🎆 Are there too many effects?

It counts the effects on each page. If everyone in the room is shouting, no one gets heard.

⚠️ What the kit does not promise

  • It reads the project but cannot see the screen. So an alert may be wrong.
  • No alerts does not mean the design is good. You make the final call with the screen open.
  • It does not measure sales or user satisfaction.

Where it comes from

The recommended components are public and checked

The kit does not reinvent anything. It points to collections of ready-made components, called libraries, each with its own official website. We checked them on 18/11/2026.

🧱 Building blocks

Collections of buttons, fields, and windows: shadcn/ui, Base UI, and Radix.

🔧 Specialists

One well-made component: Sonner for notices, Vaul for drawers, cmdk for command menus (a search box you open with the keyboard), and NumberFlow for numbers.

✨ Standout effects

Beautiful UI, Magic UI, Aceternity UI, and 21st.dev. Some have paid components: check the license for each one.

Common questions

Before you start

Do I need to know how to code?

Not to get started. Your AI runs the checker and explains the results. But the kit reads code projects, so you need to have one.

Does it change my project?

No. It only reads it. Your AI makes changes later, after you say yes.

How do I know if my project will work?

Your AI finds out in the first step. The kit was made for the kinds of websites and apps Claude Code and Codex usually build. For other kinds, some alerts may not apply. It cannot read screens from systems like WordPress, and the kit will tell you instead of saying everything passed.

How much does it cost?

Nothing. The kit and this guide are free. Some libraries for standout effects have paid components, and you can choose whether to use them.
